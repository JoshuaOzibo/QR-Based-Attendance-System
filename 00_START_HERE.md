## 🚀 Quick Start

### 1. Install Dependencies
```bash
cd frontend
npm install
```

### 2. Start Development
```bash
npm run dev
```
Frontend runs on: **http://localhost:5173/**

### 3. Start Backend (in another terminal)
```bash
cd backend
npm start
```
Backend runs on: **http://localhost:5000/**

### 4. Visit the App
- **Attendance Form:** http://localhost:5173/
- **Dashboard:** http://localhost:5173/dashboard?rollNo=12345
- **With QR:** http://localhost:5173/?sessionId=ABC123
